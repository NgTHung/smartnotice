# Annotation files

This directory holds reviewed event annotations and the Label Studio configuration used to collect spans and links. The [annotation protocol](../../docs/annotation.md) explains task export, conversion, adjudication, and applicability labeling.

`examples/events.jsonl` and `examples/profiles.jsonl` are synthetic fixtures. They illustrate the canonical schema and do not represent participant judgments. Local exports and real annotations are excluded from Git by default.
